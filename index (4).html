Python OpenCV AI/ML MediaPipe

Gesture Controlled Virtual Mouse

01
↗ GitHub

Overview: A real-time computer vision system that replaces the physical mouse with hand gestures captured via webcam, enabling touchless OS-level interaction.

Technical Depth: Leverages MediaPipe's hand landmark detection to track 21 keypoints per hand at high frame rates. Custom gesture classifiers map finger configurations to mouse actions — move, click, scroll, and drag — using OpenCV for frame processing and PyAutoGUI for system-level cursor control.

Significance: A direct application of computer vision in human-computer interaction, with strong relevance to accessibility technology and touchless UI paradigms.
